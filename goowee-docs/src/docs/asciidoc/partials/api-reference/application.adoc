[[application]]
== Application
`GooweeApplication` is the main component responsible for setting up the application. It is mainly used in `BootStrap.groovy`.

=== onInstall()
Runs only the first time the application starts.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onInstall {
            // ...
        }

    }
}
----

=== onTenantInstall()
Installs a tenant. This closure runs once when the application first starts to install the `DEFAULT` tenant, and whenever a new tenant is created through the super admin GUI.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onTenantInstall { String tenantId -> //<1>
            // ...
        }

    }
}
----
<1> The `tenantId` identifies the tenant being installed.

=== onDevInstall()
Runs once when the application is started from the IDE in the development environment. Use it to preload data for testing.

This closure does not run when the application is packaged as a JAR or WAR, or when the test environment is active.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onDevInstall { String tenantId ->
            // ...
        }

    }
}
----

=== onUpdate()
When releasing an application, you may need to update the database or another component. You can do this programmatically by adding an `onUpdate` closure.

Each closure runs only once when the application starts. Closures run in alphabetical order by the version string passed as the argument.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = { // <1>

        gooweeApplication.onUpdate('2021-01-03') { String tenantId ->
            println "${tenantId}: UPDATE N.2"
        }

        gooweeApplication.onUpdate('2021-01-02') { String tenantId ->
            println "${tenantId}: UPDATE N.1"
        }

        gooweeApplication.onUpdate('2021-01-05') { String tenantId ->
            println "${tenantId}: UPDATE N.4"
        }

        gooweeApplication.onUpdate('2021-01-04') { String tenantId ->
            println "${tenantId}: UPDATE N.3"
        }
    }
}
----
<1> The closures will be executed in the following order based on the specified version string: `2021-01-02`, `2021-01-03`, `2021-01-04`, `2021-01-05`.

=== onInit()
Initializes the application. This closure runs each time the application starts.

This call is required, even when the application has no custom initialization code.
Call `gooweeApplication.onInit()` once inside the application's `BootStrap.init`, after registering any lifecycle callbacks.
If it is missing, Goowee stops startup with a message showing the required `BootStrap.groovy` setup.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication // <1>

    def init = {

        gooweeApplication.onInit { // <2>
            // ...
        }

    }
}
----
<1> Injects an instance of `GooweeApplication`.
<2> The `onInit { ... }` closure runs each time the application starts.

=== onTenantInit()
Runs during application startup for each tenant, after plugin `beforeTenantInit()` callbacks and before plugin `afterTenantInit()` callbacks. The closure receives the tenant ID. No HTTP session is available during this startup callback.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onTenantInit { String tenantId ->
            // ...
        }

    }
}
----

=== afterLogin()
Runs after the user signs in. The session is active, so you can set session variables here.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
import grails.web.servlet.mvc.GrailsHttpSession

class BootStrap {

    SecurityService securityService // <1>

    def init = {

        securityService.afterLogin { String tenantId, GrailsHttpSession session ->
            // ...
        }

    }
}
----
<1> Injects an instance of the `SecurityService`

=== afterLogout()
Runs during logout, before the session is invalidated. Session-scoped data is still available in this callback.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    SecurityService securityService // <1>

    def init = {

        securityService.afterLogout { String tenantId ->
            // ...
        }

    }
}
----
<1> Injects an instance of the `SecurityService`
