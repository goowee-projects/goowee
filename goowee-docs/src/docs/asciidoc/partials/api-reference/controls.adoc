[[controls]]
== Controls

=== Control (abstract)

Controls are components that can hold values. They are the main way users interact with the application, and are commonly used in forms to submit those values.

Each control extends the base class `Control` and shares the following properties and methods.

==== Properties
[cols="1,1,1,7a"]
|===
|Name|Type|Default|Description

|`value`
|`Object`
|`null`
|The value held by the control.
|`valueType`
|`String`
|`null` on `Control`; concrete controls set their own type
|The type name used to serialize and deserialize the control value.
|`defaultValue`
|`Object`
|`null`
|Default value to use when no value has been assigned.
|`nullable`
|`Boolean`
|`true`
|Whether the control can hold a `null` value.
|`invalidChars`
|`String`
|`null`
|Characters that are not accepted as input. It takes precedence over `validChars` and `pattern`.
|`validChars`
|`String`
|`null`
|Characters accepted as input. It takes precedence over `pattern`.
|`pattern`
|`String`
|`''`
|A RegEx pattern to accept only specific input.
|`prettyPrinter`
|`String`
|`null`
|Name of the pretty printer used to render the value. See <<registerPrettyPrinter()>>.
|`transformer`
|`String`
|`null`
|Name of the transformer used to render the value. See <<registerTransformer()>>.
|`textPrefix`
|`String`
|Current controller name
|Prefix used to look up localized text in `messages.properties`.
|`renderTextPrefix`
|`Boolean`
|`true`
|Whether to display the `textPrefix` or not.
|`textArgs`
|`List`
|`null`
|A list of objects to pass to the localized text.
|`textStyle`
|`TextStyle`
|`BOLD`
|Text style applied by controls that render text.
|===

==== Methods
[cols="2,8a"]
|===
|Method|Description

|`onSubmit(Map)`
|Configures the event used when the control is used as a `Table` filter and its value is submitted. The default event is `enter`; some controls override it.
|===

|`String`

|`TextStyle`
|`BOLD`

- `MONOSPACE`

|`Boolean`

|`String`

|`allowClear`
|`Boolean`
|`true` for recordset options or multiple selection; otherwise `false`
|If `true` the selection can be cleared
|`autoSelect`
|`Boolean`
|`true`

|`multiple`
|`Boolean`
|`false`
|Enables multiple selections
|`search`
|`Boolean`
|`true` for recordset and map options; `false` for list and enum options

|`searchMinInputLength`
|`Integer`
|`0`

|===

==== Methods
[cols="2,8a"]
|===
|Method|Description

|`Select.optionsFromRecordset(recordset: ...)`
|Returns a `Map` of options to be used in a transition. See <<select-server-search>>. Accepts a `Map`, you can set the following arguments: `keys`, `keysSeparator`, `prettyPrinter`, `transformer`, `textPrefix`, `renderTextPrefix`, `locale`.
|`Select.optionsFromList(list: ...)`
|Returns a `Map` of options to be used in a transition. See <<select-server-search>>. Accepts a `Map`, you can set the above arguments.
|`Select.optionsFromEnum(enum: ...)`
|Returns a `Map` of options to be used in a transition. See <<select-server-search>>. Accepts a `Map`, you can set the above arguments.
|`Select.options(options: ...)`
|Returns a `Map` of options to be used in a transition. See <<select-server-search>>. Accepts a `Map`, you can set the above arguments.
|`addAction()`
|Adds an action button at the end of the control. See <<link>>.
|===

==== Events
[cols="2,8a"]
|===
|Event|Description

|`load`
|Triggered once the content is loaded
|`change`
|Triggered when the value changes
|`search`
|Triggered when the list opens and when the search text changes.
|===

[[select-server-search]]
==== Search on server
When a `search` event is configured, the control requests its initial options when the list opens and requests matching options as the user types. Each response must be a `Transition` that sets the `options` property on this `Select`.

[source,groovy]
----
c.form.with {
    addField(
        class: Select,
        id: 'activity',
        onLoad: 'onLoadActivity', // <1>
        onChange: 'onChangeActivity',
        onSearch: 'onSearchActivity', // <2>
        submit: ['form'],
        allowClear: true,
    )
}
----
<1> When a value is selected, the `load` event returns that option so the control can display its label. It returns no options when there is no selected value.
<2> The `search` action returns matching options in a `Transition`.

We need to create the following actions.

[source,groovy]
----
ActivityService activityService

def onLoadActivity() {
    def t = createTransition()
    def activities = activityService.list(id: params.activity) // <1>
    def options = Select.optionsFromRecordset(recordset: activities)
    t.set('activity', 'options', options)
    display transition: t
}

def onSearchActivity() {
    def t = createTransition()
    def activities = activityService.list(find: params.activity) // <2>
    def options = Select.optionsFromRecordset(recordset: activities)
    t.set('activity', 'options', options)
    display transition: t
}

def onChangeActivity() {
    def t = createTransition()
    // Do something...
    display transition: t
}
----
<1> `params.activity` will hold the selected id
<2> `params.activity` will hold the search string

[[telephone-field]]
=== TelephoneField
A control to input a telephone number. It inherits the properties of <<TextField>> and defaults to `inputMode: TEL`, the `fa-phone` icon, and the pattern `^[0-9\+]*$`.

[source,groovy]
----
c.form.with {
    addField(
        class: TelephoneField,
        id: 'telephone',
    )
}
----

[[hidden-field]]
=== HiddenField
A control to store a value without displaying it to the user. If no value is set, its `valueType` defaults to `STRING`; `display` and `skipFocus` default to `false` and `true`, respectively.

[source,groovy]
----
c.form.with {
    addField(
        class: HiddenField,
        id: 'hidden',
        value: 'This is not visible but it will be submitted',
    )
}
----

[[progress-bar]]
=== ProgressBar
A `ProgressBar` is a numeric control that displays a value as a progress bar. It can show either a determinate value or an animated indefinite indicator.

[source,groovy]
----
c.form.with {
    addField(
        class: ProgressBar,
        id: 'progress',
        min: 0,
        max: 140,
        value: 70,
    )
}
----

==== Properties
[cols="1,1,1,7a"]
|===
|Name|Type|Default|Description

|`min`
|`BigDecimal`
|`0`
|The lower bound used to calculate the filled portion of the bar.
|`max`
|`BigDecimal`
|`100`
|The upper bound used to calculate the filled portion. If omitted when creating the control, `indefinite` defaults to `true`.
|`value`
|`BigDecimal`
|`0`
|The current numeric value. Its position is calculated relative to `min` and `max`; the filled portion is limited to the range from 0% to 100%.
|`decimals`
|`Integer`
|`0`
|Number of decimal digits shown in the displayed value.
|`percentage`
|`Boolean`
|`true`
|When `true`, displays the normalized percentage, followed by `%`. When `false`, displays the raw value.
|`indefinite`
|`Boolean`
|Defaults to `true` if `max` is omitted, otherwise `false`.
|When `true`, displays the animated indefinite indicator. Set it to `false` to show the determinate bar. Changing `max` does not change this property.
|===

Set the control's initial `value` when adding the field. Update it later with `t.setValue(progressId, value)`. Update `min`, `max`, `indefinite`, or `percentage` with `t.set(progressId, property, value)`. Changes to `min`, `max`, or `value` recalculate the filled portion.

[source,groovy]
----
def updateProgress() {
    def t = createTransition()
    t.setValue('progress', 90)
    t.set('progress', 'percentage', false)
    display transition: t
}
----
