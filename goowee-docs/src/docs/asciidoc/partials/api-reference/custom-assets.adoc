[[branding]]
== Branding

To brand a Goowee application, add default tenant assets under
`src/main/resources/deploy/public/brand`, such as `logo.png`, `favicon.png`,
`appicon.png`, `login-logo.png`, and `login-background.jpg`. When a tenant is
installed, Goowee copies these files into its `public` directory and initializes
the `LOGO`, `FAVICON`, `APPICON`, `LOGIN_LOGO`, and `LOGIN_BACKGROUND_IMAGE`
tenant properties to point to them; change those tenant properties to use other
assets or apply tenant-specific branding. Set `LOGO_TAG` and `LOGIN_LOGO_TAG`
through Tenant Properties to display optional labels over the corresponding
logos.

[[custom-css]]
== Custom CSS

Add application-specific styles to
`grails-app/assets/stylesheets/goowee.css`. The Goowee page includes this
stylesheet automatically.

.Edit `~/demo/grails-app/assets/stylesheets/goowee.css`
[source,css,subs="attributes+"]
----
.orders-summary {
    border: 1px solid var(--border-color);
    padding: 1rem;
}
----

Use the CSS class from a component or control by passing it as `cssClass`:

[source,groovy]
----
c.addComponent(
    class: Label,
    id: 'ordersSummary',
    cssClass: 'orders-summary',
    text: 'Order summary',
)
----

[[custom-js]]
== Custom JavaScript

Add application-specific JavaScript to
`grails-app/assets/javascripts/goowee.js`. The Goowee page includes this file
automatically.

.Edit `~/demo/grails-app/assets/javascripts/goowee.js`
[source,javascript,subs="attributes+"]
----
document.addEventListener('DOMContentLoaded', () => {
    document.querySelectorAll('.orders-summary').forEach((element) => {
        element.addEventListener('click', () => {
            element.classList.toggle('is-expanded');
        });
    });
});
----

=== Loading order

Goowee loads assets in this order:

* CSS: `includes.css`, registered component stylesheets, optional `plugin.css`,
  optional `goowee.css`, then the framework's `main.css` and inline theme values.
* JavaScript: `includes.js` (shared libraries, utilities and built-in components),
  registered component scripts, optional `plugin.js`, optional `goowee.js`, then
  `main.js`, which runs `Elements.main()` through `<page:initialize/>`.

[WARNING]
====
Goowee pages already load jQuery and Bootstrap; do not import additional copies
in `goowee.js` or `goowee.css`, as duplicate libraries can interfere with
components.
====
