== API Reference
Goowee is an https://grails.org/[Apache Grails,window=_blank] plugin designed for developing enterprise applications.

=== Create an application
Use https://start.grails.org[Grails Forge,window=_blank] to generate a *Web Application* with *Java 21 or later*. Goowee does not support earlier Java versions. Then add the following repository and dependency to your newly created Grails application:

.build.gradle
[source,groovy,subs="attributes,normal"]
----
dependencies {
    ...
    implementation "org.goowee:goowee-core:{goowee-version}"
}
----

Add the following code to initialize the application:

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onInit {
            // no-op // <1>
        }

    }
}
----
<1> The `onInit` closure can be empty, but it must be declared; otherwise, the application will not be initialized and you will not be able to sign in.

=== Optional steps
To display Spring Boot and Goowee logs, add these properties to:

.grails-app/conf/application.yml
[source,yaml]
----
logging:
  level:
    org.springframework.boot.SpringApplication: INFO
    goowee: INFO
----

=== Login
Start the application from its root directory with `./gradlew bootRun`. Once it starts, open `http://localhost:8080` and sign in as the system administrator with username `super` and password `super`.

image::images/api-reference/application-running.webp[The application running]

=== URL Path
You can serve the Goowee shell under a path within your site. In this example, the shell is available at `http://localhost:8080/admin`, while the website remains at `/`. Set `SHELL_URL_MAPPING` to `/admin` and configure the landing paths users should reach after signing in and out.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication
    TenantPropertyService tenantPropertyService

    def init = {

        gooweeApplication.onTenantInstall { String tenantId ->
            tenantPropertyService.setString('SHELL_URL_MAPPING', '/admin')
            tenantPropertyService.setString('LOGIN_LANDING_URL', '/') // <1>
            tenantPropertyService.setString('LOGOUT_LANDING_URL', '/') // <2>
        }

    }
}
----
<1> After sign-in, the shell redirects to this path.
<2> After sign-out, the shell redirects to this path.

Add URL mappings for both the website root and the Goowee shell path. Here, `/` opens `WebsiteController`, and `/admin` opens the shell:

.grails-app/controllers/WebsiteUrlMappings.groovy
[source,groovy]
----
class WebsiteUrlMappings {

    static mappings = {
        "/"(controller: 'website')
        "/admin"(controller: 'shell') // <1>
    }

}
----
<1> This path must match the `SHELL_URL_MAPPING` tenant property.
