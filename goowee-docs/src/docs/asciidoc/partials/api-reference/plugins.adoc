[[plugins]]
== Plugins
Goowee uses the Apache Grails plugin infrastructure and adds several useful methods.

=== onPluginInstall()
Runs only the first time the application starts or when a Goowee plugin is added as a dependency in `build.gradle`. It installs the plugin.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.onPluginInstall { String tenantId ->
            // ...
        }

    }
}
----

=== beforeInit()
Available in Goowee plugins. It runs before the application is initialized. The session is not available, so session variables cannot be set here.

NOTE: This method is executed only when configured in a plugin, it does not get executed if implemented in the application.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.beforeInit {
            // ...
        }

    }
}
----

=== afterInit()
Available in Goowee plugins. It runs after the application is initialized. The session is not available, so session variables cannot be set here.

NOTE: This method is executed only when configured in a plugin, it does not get executed if implemented in the application.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.afterInit {
            // ...
        }

    }
}
----

=== beforeTenantInit()
Available in Goowee plugins. It runs during application startup for each tenant, before the application's `onTenantInit()` callback. The closure receives the tenant ID. No HTTP session is available during this startup callback.

Use this hook in plugins to perform setup before the application initializes a tenant. Application code can use `onTenantInit()` for its own tenant initialization.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.beforeTenantInit { String tenantId ->
            // ...
        }

    }
}
----

=== afterTenantInit()
Available in Goowee plugins. It runs during application startup for each tenant, after the application's `onTenantInit()` callback. The closure receives the tenant ID. No HTTP session is available during this startup callback.

Use this hook in plugins to perform setup after the application initializes a tenant.

.grails-app/init/BootStrap.groovy
[source,groovy]
----
class BootStrap {

    GooweeApplication gooweeApplication

    def init = {

        gooweeApplication.afterTenantInit { String tenantId ->
            // ...
        }

    }
}
----
