[[pretty-printer-properties]]
== PrettyPrinterProperties

The `PrettyPrinter` subsystem renders values in Goowee. You can configure <<components>> and <<controls>> to override user and system formatting settings. See each component's documentation for details.

All `PrettyPrinterProperties` fields are nullable. The defaults below describe the effective behavior of the relevant formatter or control; request-aware rendering can also inherit preferences from the current user.

[cols="1,1,1,7a"]
|===
|Name|Type|Default|Description

|`prettyPrinter`
|`Object`
|
|A `Class` or registered `String` name that selects a pretty printer template. When unset, the value's class is used to look up a registered template.
|`transformer`
|`String`
|
|Name of a registered transformer to apply to the value before formatting.
|`locale`
|`Locale`
|Current locale
|Locale used for message lookup and date/number formatting. Request-aware controls use the current user's locale; direct pretty printing falls back to the current thread locale.
|`renderTextPrefix`
|`Boolean`
|`true` in `PrettyPrinter`; component-specific (`false` in `Label` and `TextField`)
|Whether to resolve string values as i18n message keys. When enabled, `textPrefix` is prepended to the key.
|`textPrefix`
|`String`
|
|Optional i18n key prefix. When `renderTextPrefix` is enabled, the prefix is prepended to the string value before message lookup.
|`textArgs`
|`List`
|`[]`
|Arguments used to interpolate the resolved i18n message.
|`renderBoolean`
|`Boolean`
|`true` in `Label`
|For `Label`, enables Boolean-specific rendering: `true` displays a check mark and `false` displays no text. Setting this to `false` does not display the literal `true` or `false` text.
|`highlightNegative`
|`Boolean`
|`true` in `Label`
|For `Label`, negative numeric values are highlighted in red. In the current implementation, numeric text is assigned only when this option is enabled.
|`renderZero`
|`String`
|
|Replacement text for a numeric value of zero. When unset, zero is formatted normally.
|`renderDate`
|`Boolean`
|`true` for `LocalDateTime`
|For `LocalDateTime` values, whether to include the date portion. Has no effect when `renderDatePattern` is set.
|`renderDatePattern`
|`String`
|
|Date/time pattern applied with https://docs.oracle.com/javase/8/docs/api/java/time/format/DateTimeFormatter.html[DateTimeFormatter,window=_blank]. It applies to date, time, and date-time values and takes precedence over their other pattern options.
|`renderTime`
|`Boolean`
|`true` for `LocalDateTime`
|For `LocalDateTime` values, whether to include the time portion. Has no effect when `renderDatePattern` is set.
|`renderSeconds`
|`Boolean`
|`false`
|Whether to include seconds in `LocalTime` values and the time portion of `LocalDateTime` values. Has no effect when `renderDatePattern` is set.
|`renderDelimiter`
|`String`
|`', '`
|Delimiter used to join values in a `Map` or collection.
|`decimals`
|`Integer`
|`2` for decimal numbers; `0` for integers
|Number of decimal places used for numeric values. Integers are always formatted with zero decimal places.
|`decimalFormat`
|`String`
|`ISO_COM`
|Decimal separator for numeric values: `ISO_COM` (comma) or `ISO_DOT` (period). The current user's preference is used when available.
|`prefixedUnit`
|`Boolean`
|`false`
|For `Quantity` and `Money` values, whether to display the unit before the value. Otherwise, the unit follows the value.
|`symbolicCurrency`
|`Boolean`
|`true`
|For `Money` values, whether to display the currency symbol instead of its ISO code.
|`symbolicQuantity`
|`Boolean`
|`true`
|For `Quantity` values, whether to display a unit symbol instead of its SI code.
|`invertedMonth`
|`Boolean`
|`false`
|For date values, whether to use `MM/dd/yyyy` (`true`) instead of `dd/MM/yyyy` (`false`). Also affects date picker controls.
|`twelveHours`
|`Boolean`
|`false`
|For time values, whether to use 12-hour time with AM/PM (`true`) instead of 24-hour time (`false`).
|`firstDaySunday`
|`Boolean`
|`false`
|Whether calendar controls start the week on Sunday (`true`) instead of Monday (`false`).
|===
