Deploy anywhere

Built on Grails & Spring Boot, Goowee fits the way you run applications. Deploy on your own infrastructure or in the cloud.

  • On premises
  • Cloud

Authentication included

Access your applications as a standalone setup, with a physical token or with the identity systems your organization already uses.

  • Local username and password
  • Hardware security tokens
  • LDAP and Active Directory
  • IBM i (AS/400, iSeries, System i)
  • OIDC providers
    • Google Cloud Identity
    • Microsoft Entra ID
    • SAP Identity Authentication Service
    • Any OpenID Connect provider
