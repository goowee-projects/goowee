Quickstart

Build your first AI-powered app.

Three steps to get going

Grails

Open Grails Forge, choose Web Application and select Grails 8.0.0, then generate and download your project. Requires Java 21 or later

Grails Forge

Goowee

Download and unzip the Goowee Developer archive in your project's root. The .agents folder contains the skill and its supporting files.

Goowee Developer

Prompt

Open the project in your coding agent and start with a prompt such as:

Build a Goowee bookstore application for Books and Authors.

A couple more to go

Run

When the agent is finished, start the app from the project directory. Then open http://localhost:8080 in your browser.

Linux / macOS

$ ./gradlew bootRun

Windows

$ gradlew.bat bootRun

Deploy

Build an executable Spring Boot JAR, then launch it with Java. Replace the placeholder with the JAR filename generated in build/libs.

Linux / macOS

$ ./gradlew bootJar

Windows

$ gradlew.bat bootJar

Run the generated JAR

$ java -jar build/libs/<app-name>-<version>.jar
